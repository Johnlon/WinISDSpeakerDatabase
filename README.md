# WinISD Speaker Database

WinISD and OpenISD are loudspeaker enclosure simulators. WinISD uses `.wdr` files to store driver parameters. OpenISD runs in a browser and can import and export those files.

- **Browse current driver data.** Open [OpenISD](https://openisd.app/) and choose **New Project** to open its driver library. To use a driver in WinISD, select it and use **Export WinISD Driver (.wdr)** from the project’s export menu.
- **Find legacy WinISD Pro driver files.** The [WinISD Pro archive in OpenISD](https://github.com/Johnlon/openisd/tree/main/drivers/winisdpro) contains `.wdr` files from an older WinISD distribution for historical reference.
